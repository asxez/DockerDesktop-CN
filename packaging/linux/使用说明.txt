Docker Desktop 汉化包 - Linux 使用说明
======================================

一、安装汉化
1. 完全退出 Docker Desktop。
2. 解压 app-Debian-x86.zip。
3. 在终端进入解压目录，执行：
   chmod +x install.sh
   sudo ./install.sh
4. 按提示输入管理员密码，等待脚本自动完成备份、替换和校验。
5. 完成后按提示启动 Docker Desktop。

脚本会自动：
- 查找 Docker Desktop 安装目录（默认 /opt/docker-desktop/resources）。
- 停止 Docker Desktop 用户服务。
- 备份 app.asar 和 app.asar.unpacked。
- 替换文件并校验 app.asar。
- 备份保存在 ~/.local/share/DockerDesktop-CN/backup/<时间戳>。

二、恢复原版
在终端进入解压目录，执行：
sudo ./restore.sh
按提示选择对应备份即可。

三、常见问题
- 如果提示找不到 Docker Desktop：确认已安装 Docker Desktop，并且 /opt/docker-desktop/resources/app.asar 存在。
- 如果安装后 Docker Desktop 无法启动：运行 sudo ./restore.sh 还原。
- 如果提示版本不一致：请下载与当前 Docker Desktop 版本一致的汉化包。

四、手动安装（脚本不可用时）
1. 备份原文件。
2. 用汉化包内的 app.asar 覆盖 /opt/docker-desktop/resources/app.asar。
3. 用汉化包内的 app.asar.unpacked 覆盖 /opt/docker-desktop/resources/app.asar.unpacked。
4. 启动 Docker Desktop。
